# curve-count-media

Public video files for Curve Count social posts.

Buffer pulls each video from its link here when the post publishes, so a file must stay until its post is live. Delete it after that.

- One folder per post, named like the Dropbox folder (`freya-social-004/`).
- Masters stay in Dropbox: `[0] CURVE COUNT/Commercials/`.
- Direct link pattern: `https://raw.githubusercontent.com/mhicksimagine/curve-count-media/main/<folder>/<file>.mp4`
